The package now declares the dependencies it actually needs, so `pip install
barycenter` gives a working installation. Optional extras `remote` (reading straight
from HEASARC over https or s3) and `regions` (`--source-region-deg`) cover the rest.

Orbit files are now read by a single mission-agnostic reader, driven by a declarative
table of column names and units, and always handed on in metres. Adding a mission is
one entry in `barycenter.orbit.ORBIT_SPECS`. The global monkey-patch of PINT's
internals is gone, replaced by a `SatelliteObs` subclass that reads the same table;
importing `barycenter` no longer changes PINT's behaviour for anything else in the
process. `stingray` is no longer a dependency.
