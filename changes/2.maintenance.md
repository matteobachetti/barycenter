The package now declares the dependencies it actually needs, so `pip install
barycenter` gives a working installation. Optional extras `remote` (reading straight
from HEASARC over https or s3) and `regions` (`--source-region-deg`) cover the rest.

Orbit files are now read by a single mission-agnostic reader, driven by a declarative
table of column names and units, and always handed on in metres. Adding a mission is
one entry in `barycenter.orbit.ORBIT_SPECS`. The global monkey-patch of PINT's
internals is gone, replaced by a `SatelliteObs` subclass that reads the same table;
importing `barycenter` no longer changes PINT's behaviour for anything else in the
process. `stingray` is no longer a dependency.

Everything mission-specific now lives in one registry, `barycenter.missions.MISSIONS`.
Each entry names the `TELESCOP` substrings that identify the mission, how to read its
orbit file, what builds its clock correction, which official tool `--apply-official`
should hand it to, and the one ephemeris that tool is stuck on if it is. `core.py` no
longer mentions a mission at all, `clock.py` and `official.py` only look entries up, and
`official.py`'s hard-coded list of mission names is gone, so adding a mission is one
five-line entry plus a reference dataset. `barycenter.orbit.ORBIT_SPECS` and
`spec_for_mission` have moved into it and no longer exist.

Swift, Chandra and XMM-Newton have entries with no orbit reader, which is the registry
saying "known about, no reference data yet" rather than failing with an unhelpful error.

The CALDB clock-file fetcher is no longer NuSTAR-only. `CLOCK_CALDB_URLS` (a plain
dict of URLs, with `nuCclock` hard-coded in the code that used it) is now `CLOCK_CALDB`,
a dict of `ClockSource(url, pattern)`, so the directory and the filename glob live
together and cannot drift apart. That also fixes the offline fallback, which used to scan
the cache for `nuCclock*` whatever mission was asked for -- so a cached NuSTAR file could
have been handed back as another mission's, a silent tens-of-seconds error rather than an
error. `--apply-official` likewise stops testing for the name `nustar` and asks whether
the mission has a CALDB clock directory at all.
