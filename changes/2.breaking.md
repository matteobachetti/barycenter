The single `barycenter.barycenter` module has been split into `cli`, `core`, `orbit`,
`native`, `pintengine`, `clock`, `official`, `remote` and `utils`. The public names
(`main_barycenter`, `apply_barycenter_correction`, `correct_times`,
`get_barycentric_correction`, `read_orbit`, `barycentric_correction`) are importable
from `barycenter` itself, and the `barycenter` command is unchanged, but anything that
imported from `barycenter.barycenter` has to be updated.
