Local input files are now read where they are instead of being copied into the current
directory. The copy was only made when no file of that name was already there, so a
reprocessed observation was silently barycentred from the stale copy of the old one; runs
also left duplicates of every event and orbit file behind, and parallel runs sharing a
working directory read each other's. A relative path is now always resolved from the
caller's directory, and a missing file is reported up front. Nothing is written next to the
inputs any more, so they can sit in a read-only directory: the ASCA path, which used to
gunzip its input in place, now decompresses into its private temporary copy.

ASCA runs no longer depend on being started from the output's directory: `timeconv` used
to be pointed at reference files in the current directory while they were downloaded next
to the output. It now runs in a private temporary directory, the two reference files live
in astropy's download cache instead of beside every output, and the broken cache entries
that older versions left for those two files are repaired on first use.
